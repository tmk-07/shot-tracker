# Shot Tracker

A simple tool to keep track of makes and misses, designed for basketball shooting sessions

## Acess Site
[https://shooters.tkimify.com/](shooters.tkimify.com/)

## Features

* Simply press buttons to register a make or a miss
* Undo buttons allows users to undo last shot
* Reset button resets all makes/misses for the session
* FG% is automatically calculated

## Tech Stack

* HTML
* CSS
* JavaScript
* Browser `localStorage` for saving shot data on the user's device


Deployment:

* Deployed using Cloudflare Pages
* Static frontend hosted directly from the project files
* No backend server or database required
